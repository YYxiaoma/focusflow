# FocusFlow · 专注时钟

一个纯前端的专注计时器，无需后端、无需联网即可运行。用来实践番茄工作法：设定专注时长、记录每一段专注、按日/周查看投入分布。

## 功能

- **环形计时器**：SVG 环形进度，专注 / 短休息 / 长休息三种节奏自动切换
- **任务标签**：每次专注可绑定一个任务标签，结束后自动归档到当日记录
- **统计面板**：今日专注段数、总时长、连续专注天数，最近 7 天柱状分布
- **本地持久化**：所有记录存于浏览器 localStorage，不上传任何数据
- **快捷键**：`空格` 开始/暂停，`R` 重置，`S` 跳过当前阶段
- **主题**：浅色 / 深色一键切换，跟随系统默认

## 技术要点

| 模块 | 实现 |
|------|------|
| 计时 | `requestAnimationFrame` + 时间戳差值，避免 `setInterval` 累积漂移 |
| 状态机 | `focus → shortBreak → focus … 每 4 段进入 longBreak` |
| 持久化 | localStorage 存 `sessions[]`，按 `YYYY-MM-DD` 聚合 |
| 渲染 | 原生 DOM + CSS 变量，无任何框架与构建步骤 |

## 运行

直接用浏览器打开 `index.html` 即可，或起一个静态服务器：

```bash
python -m http.server 8080
```

然后访问 <http://127.0.0.1:8080>。

## 架构

```
┌──────────────┐   事件   ┌──────────────┐   写入   ┌──────────────┐
│  UI 层        │ ───────▶ │  Timer 状态机 │ ───────▶ │ Storage 层    │
│ (DOM + SVG)  │ ◀─────── │ (rAF 驱动)    │ ◀─────── │ (localStorage)│
└──────────────┘   渲染    └──────────────┘   读取   └──────────────┘
                                   │
                                   ▼
                          ┌──────────────────┐
                          │ Stats 聚合（7 天） │
                          └──────────────────┘
```

全部逻辑运行在单页面内，没有网络请求，因此可以离线使用。
